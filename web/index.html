    BINGO ET v3.0 Feature Clarifications

    2-Min Rounds • Cards 1–600

    1. Round Cadence & Countdown

    New game rounds start on a structured 2-minute (120-second) cycle. Minute countdown tracking is active while standalone alarm noise is kept silent/hidden.

    2. Board Card Selection (1 to 600)

    Players can select game card numbers ranging from 1 to 600, subject to active round availability and per-round card selection limits.

    3. Balance & Payment Display Rules

    User balance remains visible in the interface. Payment/deposit views focus on Birr amounts while omitting/hiding percentage-based payment metrics (such as 80% payout ratio labels).

    4. Repository & Release Build Security

    Release builds strip debug flags, enforce HTTPS-only network traffic, read signing credentials from GitHub Secrets or local key.properties (never committed), and generate signed release artifacts cleanly.
